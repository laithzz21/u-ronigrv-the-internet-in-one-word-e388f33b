Entry for the make.fun bounty **u-ronigrv-the-internet-in-one-word-e388f33b**: describe the whole internet in a SINGLE WORD. The judge weighs funniness, fit, and surprise.

## The word

**doomscrolling** — the internet, distilled: an endless feed you came to check for five minutes and somehow never left. It is funny because it is true, it fits because it names what the internet actually *does* to us now, and it surprises because the whole sprawling web — every site, argument, cat video, and rabbit hole — collapses into one very modern habit.

## What this entry does

`main.py` validates that the entry is exactly one word (letters only, lowercase, no whitespace) and prints it to stdout with NO trailing newline. It also writes the word (no trailing newline) to a file under `$MAKEFUN_OUTPUT_DIR`, else `$MAKEFUN_OUTPUT`, else a per-entry `/tmp` path, verifying the write by reading it back. Deterministic, Python 3, standard library only — no network, no clock, no randomness. It never writes into the repository directory.

## How to run

```bash
python3 main.py
```
